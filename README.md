# Grok-fix

This fixes the issue of not being able to go into settings/heavy mode on grok.

## STEPS!!!!!!!!!

1. First copy and paste the code from [https://github.com/Hammerdinnii/Grok-fix/blob/main/Fix](https://github.com/Hammerdinnii/Grok-fix/blob/main/Fix)
2. Go to Grok.com and just stay on the home page.
3. Paste the code into console and it should say "Hook ready. Click Settings now."
4. Click Settings on grok.com
5. Console should say: Captured Settings portal...
6. Now paste the code from [https://github.com/Hammerdinnii/Grok-fix/blob/main/Fix2](https://github.com/Hammerdinnii/Grok-fix/blob/main/Fix2)
7. Settings should appear on the page. Use it, then refresh.

> Order matters: hook → click Settings → attach script. Don’t refresh between those.

Enjoy using grok. Please don't use it to make ai slop though.

You can also just add a page on your bookmark bar with the script provided from https://github.com/Hammerdinnii/Grok-fix/blob/main/Bookmark%20Method
--- IT WILL FREAK OUT ON YOU!!!--- YOU JUST HAVE TO REFRESH AND EVERYTHING WILL WORK AGAIN!!!
