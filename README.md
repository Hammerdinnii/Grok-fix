# Grok-fix

This fixes the issue of not being able to go into settings/heavy mode on grok. 

STEPS!!!!!!!!!

First copy and paste the code from https://github.com/Hammerdinnii/Grok-fix/blob/main/Fix
Go to Grok.com and just stay on the home page.
Paste it into console and it should say "Hook ready. Click Settings now."
Click Settings on grok.com
Console should say: Captured Settings portal...
Now paste the code from https://github.com/Hammerdinnii/Grok-fix/blob/main/Fix2
Settings should appear on the page. Use it, then refresh.
Order matters: hook → click Settings → attach script. Don’t refresh between those.

Enjoy using grok. Please don't use it to make ai slop though.
